# ADR 018: 검색 적합성 판정 — 고정 유사도 임계값 금지

> **Date:** 2026-10-30
> **Status:** Accepted

---

## 배경

현재 검색은 pgvector 코사인 **단일 채널**이다([ADR-010](010_Korean_Fulltext_Search.md) 배경과 동일).
이 구성은 **코퍼스에 답이 없는 질의에도 항상 상위 N건을 반환한다.**

예: 블로그 코퍼스는 홈트레이닝·제로웨이스트·캠핑·반려동물·전기차충전 5종이고
치질 관련 문서가 없다. 그런데 `"치질 수술 후 주의사항"` 질의는 0.8856으로
`"강아지 중성화 수술 전후 체크리스트"`를 1위로 돌려준다. 동작은 정상이다 —
**의미상 가장 가까운 문서가 맞다.** 없는 것은 "없다고 말하는 능력"이다.

최초 대응안은 **코사인 유사도 0.87 고정 임계값**이었다. 이 ADR은 그 안을 기각한다.

## 측정

질의 19건(정답 있음 11 / 없음 8)으로 실측했다. 상세는
[database/search_threshold_probe.md](../database/search_threshold_probe.md).

| 지표 | 정답 있음 최저 | 정답 없음 최고 | 분리 |
|---|---|---|---|
| **코사인 top1** | 0.8638 (`quantum computing qubit`) | 0.8856 (`치질 수술 후 주의사항`) | **겹침** |
| top1 − top50 간격 | 0.0187 | 0.0282 | **겹침** |
| 키워드 cov@10 | 0.233 | 0.720 | **겹침** |
| 최희귀어 DF% | 0.63% | 25.3% | **겹침** |

**정답이 있는 질의의 최저 점수가, 정답이 없는 질의의 최고 점수보다 낮다.**
0.87로 자르면 정답 있는 질의가 잘리고, 0.886으로 올리면 2건이 잘린다.
어떤 고정값도 두 집단을 가르지 못한다.

## 왜 가를 수 없는가 — 모델 사양이다

**적재 방식이나 청킹의 결함이 아니다.** e5 계열은 InfoNCE 대조학습에
**temperature 0.01**을 써서 코사인 점수를 0.7~1.0의 좁은 구간으로 밀어 넣는다.
모델 저자가 모델 카드에 직접 적은 내용이다.

> This is a known and expected behavior as we use a low temperature 0.01 for
> InfoNCE contrastive loss. (…) **what matters is the relative order of the
> scores instead of the absolute values.**
> — `intfloat/e5-large-v2` README

즉 **절대값에 의미를 부여하는 설계 자체가 모델 사용법에 어긋난다.**
0.84와 0.93의 차이는 "관련 없음"과 "관련 있음"이 아니라 순위 정보일 뿐이다.

## 결정

1. **코드 어디에도 코사인 유사도 절대값 컷오프를 두지 않는다.**
   `WHERE 1 - (embedding <=> q) > 0.8x` 형태는 금지한다.
   필요한 것은 "상위 k를 가져온 뒤 **다른 신호로** 판정"이다.

2. **"결과 없음" 판정은 [ADR-010](010_Korean_Fulltext_Search.md)의 키워드 채널로 한다.**
   벡터 점수가 못 주는 직교 신호가 거기 있다. 정답 없는 질의에서
   키워드 적중은 **0.00까지 떨어지지만** 코사인은 0.84 밑으로 내려오지 않는다.

3. **판정 규칙 1순위 후보는 "질의의 최희귀어가 상위 10건에 실제로 출현하는가"다.**
   19건 중 16건 적중. 중요한 것은 **오류 방향**이다.

   | | 건수 | |
   |---|---|---|
   | 정답 있는 질의를 "결과 없음"으로 버림 | **0 / 11** | 가장 피해야 할 오류가 없다 |
   | 정답 없는 질의를 그대로 보여줌 | 4 / 8 | 현재 동작과 동일 — 더 나빠지지 않는다 |

   영어 질의 `quantum computing qubit`도 통과시켰다(희귀어 `computing`이
   한국어 기사 본문에 원문 그대로 섞여 있다).

4. **최종 순위 결합은 RRF**로 한다. [ADR-010](010_Korean_Fulltext_Search.md) 결정 그대로이며 변경 없다.

5. 위 규칙으로도 남는 난제는 **재순위(cross-encoder)** 로 넘긴다. 이 ADR의 범위 밖이다.

## 전제 — ADR-010 구현이 선행되어야 한다

키워드 채널은 **한국어 형태소 분석이 없으면 측정 자체가 신뢰할 수 없다.**

| 어절(조사 포함) | DF | 어간 | DF | 배수 |
|---|---|---|---|---|
| 대역폭**을** | 0.23% | 대역폭 | **15.04%** | **65배** |
| 맨몸**으로** | 0.28% | 맨몸 | **2.65%** | 9.5배 |

조사 하나 때문에 "코퍼스에 없다"는 판정이 나온다.
ADR-010이 Kiwi 앱단 토큰화를 택한 근거가 여기서 실측으로 재확인된다.

> 2026-10-30 기준 ADR-010은 **Accepted이나 미구현**이다(`kiwipiepy`·tsvector 코드 없음).
> 현재 검색은 설계된 2채널 중 **벡터 1채널만 돌고 있다.**

## 한계 — 이 수치를 성능 지표로 쓰지 말 것

- 질의 19건은 **자체 구성 소규모 세트**이고 정답 유무 라벨도 직접 붙였다.
  `고양이 사료 추천`처럼 라벨 자체가 애매한 건이 있다.
- 키워드 매칭은 형태소 분석기가 없어 **부분문자열 + 접미 1~2자 절삭 근사**로 대체했다.
  이 근사는 `HBM`→`HB`, `대장내시경`→`대장내시`처럼 과도하게 자르는 부작용이 있었다.
- **흔한 말로만 구성된 질의는 키워드로 해결되지 않는다.**
  `"국내 기업 투자 확대 계획"`은 어절이 전부 고빈도(국내 444, 확대 897)여서
  답이 없는데도 모든 키워드 지표가 "확신"을 가리킨다. 재순위가 필요한 영역이다.

## 재검토 조건

- ADR-010 구현 후 **동일 19건 + 확장 평가셋으로 재측정**한다. 형태소 분석이 들어가면
  수치가 전부 바뀐다.
- 재순위 모델을 도입하면 판정 주체를 재순위 점수로 옮길지 재검토한다.
  단, 재순위 점수도 확률이 아니므로 **고정 컷오프 금지 원칙은 그대로 적용된다.**
