# 내부 개발 콘솔 (프로토타입)

```
PYTHONPATH=. python scripts/run_console.py
→ http://127.0.0.1:8000/console/
```

구현

```
src/api/console.py          콘솔 전용 API (/v1/console/…)
src/api/static/
├── index.html              뼈대만 (32줄)
├── css/console.css
└── js/
    ├── core.js             상태·helper·라우팅
    ├── app.js              진입점 — 화면 등록
    └── {ops,find,detail,graph,bundle,review,label,struct}.js   화면 1개당 1파일
```

**빌드 체인이 없다.** 브라우저가 ES 모듈을 그대로 읽는다 — `npm` · `node_modules` ·
빌드 산출물이 저장소에 없고, 고칠 때 새로고침만 하면 된다. 케이웨어가 자기 스택으로
다시 만들 것이므로 **여기 쏟는 도구 설정은 어차피 버려진다.**

`core.js`는 화면을 import하지 않는다 — 하면 순환이 된다. `app.js`가 등록한다.
생성한 HTML의 `onclick`이 닿는 전역은 `window.C` 하나뿐이고, 각 화면이 자기 것만 올린다.

---

## 1. 이건 포털이 아니다

실제 사용자 화면·디자인·배포는 **케이웨어 과업**이다
(NEXT_STEPS D1 목표선 "운영 대시보드 연계(케이웨어 접점)").
여기 있는 것은 우리가 쓰는 프로토타입이고, 목적이 셋이다.

1. 연구개발계획서의 기능이 **실제 데이터 위에서** 도는지 눈으로 확인
2. 사람이 판단해야만 진도가 나가는 일(관계 검토·라벨링)을 **실제로 처리**
3. 케이웨어에 넘길 C6 OpenAPI의 **첫 소비자**가 되어 빠지거나 어긋난 것을 찾기

3번은 만들자마자 효과가 있었다 — 아래 §5.

## 3. 권한을 보지 않는다

`/v1/*` 공개 API는 `visibility`로 거르지만 **콘솔은 거르지 않는다.** 총괄 관리자
시점으로 전부 본다. 권한 관리는 케이웨어 쪽에 붙인다.

⚠️ 그래서 **127.0.0.1에만 묶는다.** `scripts/run_console.py`가 호스트를 고정한다.

## 4. 정형 탭은 비어 있다 — 의도된 것이다

`meta_datagokr_file` 0건, `meta_datagokr_file_vec` 0건이고 저장 형식(`vec_role`)과
임베딩 모델 규약이 와이즈넛 협의 중이다(D-2). 지금 화면을 만들면 합의 결과에 따라
다시 만들게 된다. **비워 두는 편이 "정형이 아직 안 들어왔다"를 가장 정확히 보여준다.**

화면에는 정형·비정형의 구조적 차이도 함께 적어 둔다 — 정형은 원천에 데이터셋이
이미 있어 파싱으로 채우고, 비정형은 원천에 데이터셋 개념이 없어 사람이 정의한다.

## 5. 붙여 보니 바로 나온 것 (2026-11-04)

| 발견 | 내용 |
|---|---|
| 파라미터 이름 불일치 | 화면이 `/v1/search?why=true`를 불렀는데 실제 이름은 **`explain`**이다. 오류가 나지 않고 `tokens`·`rarest_token`만 조용히 빈다 |
| 응답 키 불일치 | 최희귀어의 키는 `term`이 아니라 **`token`** |
| `keywords` 컬럼이 사라짐 | 미리보기의 자격증명 컬럼 차단이 부분 문자열(`key`) 검사라 **`keywords`·`search_keyword`가 걸려 안 보였다.** 낱말 단위 검사로 고쳤다 |
| 고립된 외부 데이터셋 | CKAN 연합 30건은 검색에는 걸리는데 **관계가 0건**이라 관계 지도에서 외톨이다 (D-4) |
| **동시 요청이 서로를 죽였다** | 화면 하나가 API 셋을 동시에 부른다. 커넥션은 프로세스당 하나라 **한 요청의 실패한 SELECT가 다른 요청을 `InFailedSqlTransaction`으로** 죽였다. 그 자리는 고쳤지만 구조는 남아 있다 — NEXT_STEPS §6.2 |

앞의 셋은 **화면이 없으면 드러나지 않는 종류**다. API는 200을 돌려주고 있었다.
마지막 것은 더하다 — **사람이 한 번에 하나씩 부르는 동안에는 영원히 안 나온다.**

## 6. 쓰기는 둘뿐이다

`POST /v1/console/review/relations`(관계 승인·거부)와
`POST /v1/console/labeling`(라벨 채점). 둘 다 사람 판단을 기록하는 경로다.

- 관계: B2를 다시 돌려도 사람이 바꾼 행은 지워지지 않는다
  (`relations/store.py`가 `method='embedding' AND status='PENDING'`만 지운다)
- 라벨: 파일에 **바로** 쓴다. 중간 저장 장치를 두면 브라우저를 닫는 순간 날아간다
