# 데이터셋 공통 분류 (category)

> **Last Updated:** 2026-10-27
> 출처: 와이즈넛 「데이터셋 공통 분류(category) 정의」
> 적용 위치: `dcat_dataset.category` (JSONB NOT NULL DEFAULT `'[]'`, GIN 인덱스)

---

## 1. 목적과 theme과의 구분

원천 포털마다 분류 체계가 달라(공공데이터포털은 '대분류 - 소분류', KOSIS는 주제·통계 경로)
원천 분류만으로는 서로 다른 포털의 같은 분야 데이터를 하나로 묶을 수 없다.
**국가지식정보 통합플랫폼 「디지털 집현전」의 주제 분류를 준용**해 공통 분류를 둔다.

| 구분 | `theme` | `category` |
|---|---|---|
| 내용 | 원천 포털이 부여한 분류 **원문** | **공통 분류** (디지털 집현전 주제 분류) |
| 분류 체계 | 원천 포털마다 상이 | 모든 데이터에 동일 |
| 용도 | 원천 정보 보존 | 포털 전체 분류·필터링 |
| 예 (공공데이터포털 「충청남도 계룡시_보육시설」) | `["사회복지", "보육·가족및여성"]` | `["사회 > 복지", "교육 > 유아"]` |
| 예 (KOSIS 「결핵종류별 결핵 (신)환자 수 및 율」) | `["보건", "결핵환자신고현황"]` | `["의료 > 질병관리", "의료 > 공중보건"]` |

## 3. 부여 규칙

- 데이터셋당 **1~3개** 부여, **첫 번째 값이 대표 분류**
- 분류표에 있는 값만 허용, 같은 값 중복 불가
- 정형 부여 방법(와이즈넛)
  1. 제목·설명·키워드·컬럼명을 근거로 **언어 모델이 분류표 범위 안에서 선택**
  2. 모델 응답이 없거나 범위 밖 값만 나오면 → **데이터셋 요약 임베딩과 가장 가까운 중분류 1개**

## 4. 비정형 부여 방법 (모비젠)

> 💡 **외부 LLM 없이도 구현할 수 있다.**
> [ADR-013](../adr/013_No_External_LLM_API.md)으로 외부 LLM API를 쓰지 않기로 했는데,
> 와이즈넛 정의 문서의 **2단계 폴백이 그대로 임베딩 기반**이다.
> 이 경로를 주 경로로 쓰면 제약과 충돌하지 않는다.

- 🟩 **최소선 — 임베딩 zero-shot**
  76개 중분류 라벨을 `'대분류 > 중분류'` 형태로 임베딩해 두고, 데이터셋의
  `title + description + keywords` 임베딩과 코사인 유사도를 계산해 상위 1~3개를 부여한다.
  기존 `paraphrase-multilingual-mpnet-base-v2`(768차원)를 그대로 쓴다.
  `perf_eval/metadata_theme_classification/`에 라벨 임베딩 zero-shot 코드가 이미 있어 재사용 가능.

- 🟦 **목표선 — 로컬 sLLM 선택 + 임베딩 폴백**
  와이즈넛 방식과 동일한 2단 구조. 로컬 `llama-server`로 분류표 범위 안에서 선택하게 하고,
  응답이 없거나 범위 밖이면 임베딩 최근접으로 떨어뜨린다.

- **검증**: 부여 결과가 분류표 안의 값인지 INSERT 전에 확인한다(앱 레벨). 중복 제거 필수.
  ⚠️ `category`에는 CHECK 제약이 없으므로 **DB가 오타를 막아주지 않는다.**

## 4-1. 비정형 `theme` 작성 방침 (2026-10-27 결정)

`theme`은 "원천 포털이 부여한 분류 원문"인데 비정형은 원천이 포털이 아니다.
**와이즈넛에 예시를 묻지 않고 우리가 먼저 채운 뒤, 상대 샘플값을 보고 필요하면 조정한다.**
물어보고 기다리는 것보다 채워 놓고 맞추는 편이 빠르다.

| source_type | `theme`에 넣을 값 | 근거 |
|---|---|---|
| `video` | YouTube `category_id`의 카테고리명 (+ `topic_categories`) | 플랫폼이 부여한 분류 원문에 가장 가깝다 |
| `news` / `blog` | `search_keyword` | 수집 기준이 된 주제어 |
| `shopping_insight` / `persona_insight` | `category_name` (`>` 구분 경로) | 네이버 카테고리 분류 원문 |

- `theme`은 **원문 보존**이 목적이므로 값을 정규화하거나 공통 분류로 번역하지 않는다.
  공통 기준이 필요한 쪽은 `category`가 담당한다.
- 와이즈넛 샘플을 받은 뒤 표기 방식이 다르면 그때 맞춘다. 되돌리기 쉬운 변경이다.

## 5. 조회

```sql
-- 중분류 필터
SELECT * FROM dcat_dataset WHERE category ? '의료 > 공중보건';

-- 대분류 필터
SELECT * FROM dcat_dataset d
 WHERE EXISTS (SELECT 1 FROM jsonb_array_elements_text(d.category) t
                WHERE split_part(t, ' > ', 1) = '의료');
```
