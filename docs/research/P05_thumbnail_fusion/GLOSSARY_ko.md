# P05 용어 사전 (정확한 정의 + 과대주장 방지 + 표준 표기)

> 목적: 논문·문서에서 용어를 **우리가 실제로 측정한 것**에 맞게 좁게 쓰기 위한 기준.
> "학술적으로 가능한 넓은 뜻"이 아니라 **이 연구에서의 조작적 정의(operational definition)** 를
> 표준으로 삼는다. 표기·해석은 이 문서를 따른다.

## 1. 핵심 지표·대상

| 용어(표준 표기) | 우리 정의(측정한 것) | ⚠️ 이렇게 쓰지 말 것 |
|---|---|---|
| **시각–텍스트 의미 간극 (gap; Visual–Text Semantic Gap)** | `1 − cos(center(썸네일 임베딩), center(제목 임베딩))`. CLIP 공동공간에서 썸네일과 제목의 **비정렬(misalignment) 정도**(영상당 1값). **인간이 느끼는 의미 차이가 아니라 임베딩 공간 표현 간 비유사도**. | "썸네일이 담은 정보량", "시각 정보의 유용성", "제목에 없는 정보의 양", "인간 지각 의미 차이"로 **정의 금지**(그건 gap이 관련되는지 *검증*할 대상이거나 다른 개념). |
| **정합(성) (alignment)** | CLIP 공동공간에서 썸네일–제목 코사인 유사도. gap은 mean-centering 후 이 코사인을 **역변환(1−cos)** 한 값(값이 클수록 덜 정합). '여집합'으로 표현하지 않음(cos∈[−1,1]→1−cos∈[0,2]). | "사실 일치/정확성"과 혼동 금지(의미 벡터 정렬일 뿐). |
| **modality gap** (선행연구[10]) | 이미지 클러스터와 텍스트 클러스터가 공동공간에서 **체계적으로 떨어져 있는** 기하 현상(Liang 2022). | **우리 gap과 다름.** 우리는 모달별 mean-centering으로 modality gap 성분을 **제거한 뒤** 영상별 잔차 비정렬을 잰다. 둘을 같은 것으로 쓰지 말 것. |
| **시각 정보의 기여 (visual contribution)** | 텍스트 검색에 시각 채널을 더했을 때의 **순위 변화**(Δrank/지표 개선)로 측정. | 썸네일의 "내재적 가치"나 "정보량"으로 쓰지 말 것 — **검색 결과에서 측정되는 효과**만 지칭. |
| **Δrank (순위 개선폭)** | 관련(qrels≥1) 영상에 대해 `rank_text − rank_fusion`. 양수=융합이 순위를 올림. | 무관 영상에는 정의 안 함(계산에서 제외). |
| **gap이 높다 (high gap)** | 썸네일이 제목과 **의미적으로 많이 어긋난다**는 뜻. | "썸네일이 더 유용/정보가 많다"로 해석 금지. |

## 2. 방법·시스템

| 용어(표준 표기) | 우리 정의 | ⚠️ 주의 |
|---|---|---|
| **(late) fusion / 융합** | **점수 수준 late fusion**: `α·minmax(sim_text)+(1−α)·minmax(sim_visual)`, α=0.5 primary. | feature concat·learned weighting 아님. "새 융합 기법 제안" 아님(측정 도구). |
| **검색 (retrieval)** | **우리 시스템**이 코퍼스 840편을 임베딩 유사도로 정렬. Text/Visual/Fusion 3방식. | **YouTube 검색 순위와 무관**. "YouTube 검색"과 혼동 금지. |
| **정답지 (qrels)** | pooling 후보 (쿼리,영상) 쌍에 **3인 median-of-3**로 매긴 관련도 0/1/2. | "정답 하나"가 아니라 등급 라벨 집합. |
| **관련성 등급** | 2=직접관련 / 1=부분 / 0=무관. NDCG는 등급, MRR/Recall은 ≥1 임계. | — |
| **is_short / Short** | `youtube.com/shorts/{id}` 리다이렉트 판별로 라벨(200=Short). 코퍼스 12.5%. | duration만으로 판단 금지(≤3분 세로형도 Short). |

## 3. 통계·해석 (과대주장 방지 핵심)

| 용어(표준 표기) | 우리 정의 | ⚠️ 주의 |
|---|---|---|
| **연관 (association)** ✅ | primary 분석 = **Spearman 상관**(gap↔median Δrank). "연관/관련"으로 서술. | **"예측(prediction/predictor)" 지양** — 상관 유의성은 예측력의 직접 증거 아님. 결과가 강하면 "유의한 연관", 그 이상은 별도 검증 필요. |
| **대표성 (representative)** | **쓰지 않음/좁게만.** 쿼리셋은 사용자 검색 빈도의 확률표본이 **아니며**, "플랫폼에서 관찰 가능한 검색 관심사의 후보를 구성한 평가용 쿼리 집합"(Suggest는 의도 분포의 직접 관측이 아닌 프록시). 코퍼스는 "카테고리 층화표본". | "사용자 분포를 대표한다"고 주장 금지. |
| **coverage (커버리지)** | 두 뜻을 **구분**: (a) **pooling coverage**=여러 시스템 Top10 합집합으로 관련 후보를 빠짐없이 라벨링, (b) **query–corpus coverage**=쿼리에 대응하는 관련 영상이 코퍼스에 존재하는 정도(zero-relevance로 사후 점검). | 두 뜻을 섞어 쓰지 말 것. |
| **설명 (characterize/explain)** | "gap으로 시각 기여의 **조건을 특성화(characterize)**한다" 수준. | **"Explainable retrieval(설명가능 검색, XAI)"로 주장 금지** — 모델 판단 근거를 설명하는 XAI가 아님. 키워드에서 삭제(→ "시각–텍스트 의미 간극/썸네일"로 대체). |

## 4. 동음이의 주의

- **"기여"** — ① 논문의 기여(contribution, §1) ② 시각 정보의 기여(visual contribution, 측정 대상). 문맥으로 구분하되, 측정 대상일 때는 "시각 정보의 기여" 또는 "검색 기여"로 명시.
- **"gap"** — 항상 **우리 지표(시각–텍스트 의미 간극)**. modality gap은 반드시 "modality gap"으로 풀어 씀.

## 5. 일관 사용 규칙 (요약)

1. gap = **비정렬 지표**(정의). 유용성·정보량이 아님. 유용성 관련성은 **실험으로 검증**.
2. gap↔Δrank는 **"연관"**(상관). "예측"으로 쓰지 않는다.
3. 융합 = late fusion α=0.5(도구), 새 기법 아님.
4. 검색 = 우리 시스템의 재정렬(YouTube 순위 아님).
5. 쿼리셋 = 평가용 후보 집합(사용자 분포 대표 아님).
6. "explainable retrieval" 미사용 → "시각 기여 조건의 특성화/분석".
7. modality gap ≠ 우리 gap(centering으로 modality gap 제거 후 잔차).
