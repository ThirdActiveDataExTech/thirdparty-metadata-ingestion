## 초록

P03(트랜스크립트 기반 LLM 메타데이터 생성)은 텍스트 채널만 활용하며, 썸네일에
담긴 제품·인물·감성 톤 같은 시각 정보는 트랜스크립트에 전혀 언급되지 않는 경우가
많다. 본 연구는 비전-언어 모델(VLM; LLaVA 계열, Groq Vision API)을 이용해
한국어 YouTube 썸네일에서 시각적 메타데이터 4종(시각 요약·주요 객체·감성·레이아웃
유형)을 자동 추출하는 파이프라인을 구축하고, 트랜스크립트 기반 LLM 메타데이터
(P03)와의 정보 보완성을 실증했다. 영상 800편 중 100편의 visual_summary를 3인이
1–5점으로 평가한 결과 평균 3.77점을 얻었다(GPT-4V를 upper bound baseline으로
병행 평가한 결과는 4.40점, 평가자 간 일치도 Krippendorff's α=0.71). 트랜스크립트
유무(`has_content`)별로 신규 정보 비율을 측정한 결과 has_content=TRUE 그룹에서
34.2%, has_content=FALSE 그룹에서 71.4%로 나타나 전체 가중 평균 45.4%를 기록했다
(Mann-Whitney U, *p* < 0.001로 그룹 간 차이 유의). 50개 테스트 쿼리에 대한
4조건(A/B/C/D) Ablation 검색 실험에서 VLM 메타를 추가한 조건 C는 API 메타만
사용한 조건 A 대비 MRR@10을 전체 평균 +0.023 향상시켰으나(Friedman 검정,
χ²=18.7, *p*=0.00031; 단 A-C 사후검정은 Bonferroni 보정 후 유의하지 않음,
*p*=0.041), 그룹별로 나누어 보면 has_content=FALSE 영상에서는 Δ=+0.068로 해석
기준(+0.03)을 크게 초과한 반면 has_content=TRUE 영상에서는 Δ=+0.010에 그쳤다.
즉 VLM이 포착한 신규 정보의 "양"(신규 정보 비율)은 목표치를 넘었지만, 그 신규
정보가 검색 성능 향상이라는 "효과"로 전환되는 정도는 트랜스크립트 유무에 따라
크게 갈렸다 — 본 연구는 이 불일치의 원인을 정성적 사례 분석과 함께 논의한다.

**Keywords:** vision-language model, VLM, thumbnail metadata generation, multimodal
complementarity, Jaccard similarity, novel information ratio, Korean YouTube, information
retrieval, Groq Vision API

## 1. 서론

### 1.1 연구 배경 및 문제 정의

YouTube 메타데이터 자동 생성 연구는 주로 트랜스크립트 텍스트를 LLM에 입력해
요약·키워드·카테고리 등을 생성하는 방식(P03)에 집중되어 왔다. 그러나 트랜스크립트는
음성으로 언급된 정보만 담을 뿐, 썸네일에 등장하는 제품·인물·감성 톤·레이아웃
구성처럼 화자가 말로 설명하지 않는 시각 정보는 포착하지 못한다.

비전-언어 모델(VLM)은 이미지에서 자유형식 텍스트를 생성할 수 있어 이 공백을 메울
후보로 자연스럽다. 그러나 VLM을 이용해 썸네일에서 구조화된 메타데이터를 추출하고,
이를 트랜스크립트 기반 메타데이터와의 보완 관계로 정량화하며, 최종적으로 검색
성능 향상까지 이어지는지를 end-to-end로 검증한 연구는 확인되지 않는다. 또한 GPU
없는 환경에서 무료 Vision API(Groq)만으로 이 파이프라인이 실용적으로 구현
가능한지에 대한 실증도 그 자체로 연구 가치가 있다.

### 1.2 연구 질문

> "VLM이 썸네일에서 추출한 시각 메타데이터는 트랜스크립트가 포착하지 못하는 신규
> 정보를 충분히 포함하며, 이를 추가했을 때 검색 성능이 유의미하게 향상되는가?"

### 1.3 기여점

1. VLM 썸네일 메타데이터 4종 추출 파이프라인 구축, Groq Vision API(`llava-v1.5-7b`) 기반
2. 트랜스크립트 LLM 메타(P03) vs. VLM 썸네일 메타의 정보 보완성을 Jaccard 기반
   신규 정보 비율로 정량화
3. 트랜스크립트 없는 영상(`has_content=FALSE`)에서 VLM의 대체 정보원 가능성을
   그룹별 비교 실험으로 실증 — 특히 전체 평균 검색 기여도와 하위 그룹 기여도가
   크게 다를 수 있음을 발견
4. 4조건(A/B/C/D) Ablation 검색 실험을 통해 VLM 메타 추가의 검색 기여도를
   통계적으로 검증하고, "신규 정보의 양"과 "검색 성능 향상 효과" 사이의 불일치
   가능성을 실증적으로 제기
5. Groq Vision API 무료 tier로의 실용적 파이프라인 구현과 `meta_youtube_video_ai`
   테이블로의 스키마 확장 설계를 통해 운영 환경 적용 가능성을 평가

### 2.1 선행 연구 대비 위치

기존 VLM 연구(LLaVA, MiniGPT-4)는 일반 이미지 이해 능력 향상 자체에 집중하며,
한국어 YouTube 썸네일이라는 특정 도메인에서 구조화된 4종 메타데이터를 추출하는
프롬프트 설계와 그 실용성을 검증하지 않는다. CLIP류 모델은 유사도 계산에는
강하지만 자유형식 서술이나 범주형 라벨을 직접 생성하지 못한다. Video-LLaMA 등
비디오 전체를 다루는 모델은 연산 비용이 커 GPU 없는 환경에 적합하지 않다. 본
연구는 썸네일 단일 이미지만으로 파이프라인을 구성해 무료 Vision API에서도
실용적으로 구현 가능한지를 검증하며, 트랜스크립트 기반 메타와 VLM 썸네일 메타
사이의 정보 보완성을 정량화하고 이것이 실제 검색 성능 향상으로 이어지는지를
end-to-end로 검증한 최초의 시도로 위치한다.

## 3. 제안 방법

### 3.1 VLM 추론 파이프라인

```
썸네일 URL 다운로드
    ↓
Groq Vision API (llava-v1.5-7b) 호출
    ↓ 프롬프트:
    "다음 YouTube 썸네일을 분석하여 JSON 형식으로 출력하라:
     visual_summary (1문장), dominant_objects (최대 3개 배열),
     visual_emotion (positive/neutral/dramatic/humorous 중 1개),
     layout_type (face-centered/diagram/product/collage 중 1개)"
    ↓
JSON 파싱 → meta_youtube_video_ai 확장 컬럼에 저장
```

### 3.2 정보 보완성 분석

```
Jaccard 유사도  = |K_transcript ∩ K_visual| / |K_transcript ∪ K_visual|
신규 정보 비율  = |K_visual \ K_transcript| / |K_visual|
```

`has_content=TRUE`/`FALSE` 그룹 각각에 대해 별도로 계산한다.

### 3.3 Ablation 검색 실험 설계

```
조건 A: API 메타만 (제목 + 설명 + 태그)
조건 B: A + 트랜스크립트 LLM 메타 (P03 방법)
조건 C: A + VLM 썸네일 메타 (제안 방법)
조건 D: A + B + C (전체 결합)
```

## 5. 평가 방법

### 5.1 비교 대상

| 방법 | 설명 |
|------|------|
| 조건 A (Baseline) | API 메타데이터 텍스트 임베딩만 |
| 조건 B | A + 트랜스크립트 LLM 메타 (P03 방법) |
| 조건 C | A + VLM 썸네일 메타 (제안 방법) |
| 조건 D | A + B + C (최대 결합) |

### 5.2 지표

Human Rating(1–5), GPT-4V Rating(1–5), 신규 정보 비율(%), MRR@10, NDCG@10,
Friedman p-value, JSON 파싱 성공률·API 오류율

### 5.3 주요 개념 설명

**Jaccard 유사도** — `|교집합| / |합집합|`. 0이면 완전히 다르고 1이면 완전히
같다. 낮을수록 두 채널(트랜스크립트/썸네일)이 서로 다른 정보를 담고 있어 보완
관계가 강함을 뜻한다.

**신규 정보 비율** — `|K_visual \ K_transcript| / |K_visual|`. VLM이 찾아낸
키워드 중 트랜스크립트 LLM 메타에는 없는 것의 비율. 30% 이상이어야 VLM 추가
가치가 있다고 판단한다.

**Friedman 검정** — A/B/C/D 4조건에 대해 동일한 50개 쿼리를 적용한 MRR@10
값이 조건 간에 통계적으로 다른지를 검정하는 비모수 방법. p < 0.05이면 4조건
중 적어도 하나가 유의하게 다르다는 것만 알려주며, 어느 조건 쌍이 다른지는
사후 검정이 필요하다.

### 5.4 해석 기준 (성공 조건)

- Human Rating 평균 ≥ 3.5 → 실용 수준의 VLM 메타데이터 품질
- 신규 정보 비율 > 30% → 트랜스크립트와 충분히 독립적인 정보 제공
- 조건 C가 조건 A 대비 MRR@10 > +0.03 → VLM 메타의 검색 기여 입증

## 6. 실험 결과

> ⚠️ 이하 수치는 전부 가상 데이터입니다.

### 6.1 VLM 메타데이터 품질 인간 평가

| 평가 기준 | VLM (Groq llava-v1.5-7b) | GPT-4V (upper bound) |
|-----------|---------------------------|------------------------|
| 정확성 | 3.91 | 4.52 |
| 구체성 | 3.58 | 4.27 |
| 유용성 | 3.81 | 4.41 |
| **평균** | **3.77** | **4.40** |

평가자 간 일치도: Krippendorff's α = 0.71 (substantial agreement)

해석 기준(≥3.5) **충족**. GPT-4V 대비 0.63점 낮으나, 무료 tier 소형(7B) 모델
로서는 합리적인 품질 손실 수준으로 판단된다.

### 6.2 정보 보완성 분석 (신규 정보 비율)

| 그룹 | 신규 정보 비율 | Jaccard 유사도 | 표본 수 |
|------|---------------|----------------|---------|
| `has_content=TRUE` | 34.2% | 0.29 | 560 |
| `has_content=FALSE` | 71.4% | 0.06 | 240 |
| 전체 (가중 평균) | 45.4% | 0.22 | 800 |

Mann-Whitney U 검정 (그룹 간 신규 정보 비율 차이): U = 21,340, *p* < 0.001 —
`has_content=FALSE` 그룹의 신규 정보 비율이 유의하게 높다. 해석 기준(>30%)은
전체·그룹 모두에서 **충족**되며, 특히 트랜스크립트가 없는 영상일수록 VLM이
제공하는 정보가 거의 전적으로 신규 정보임을 확인했다(예상과 일치).

### 6.3 4조건 Ablation 검색 실험

| 조건 | 설명 | MRR@10 | NDCG@10 |
|------|------|--------|---------|
| A | API 메타만 | 0.518 | 0.547 |
| B | A + 트랜스크립트 LLM 메타 | 0.571 | 0.598 |
| C | A + VLM 썸네일 메타 | 0.541 | 0.564 |
| D | A + B + C | 0.589 | 0.612 |

Friedman 검정 (4조건, MRR@10): χ² = 18.7, *p* = 0.00031 (전체적으로 조건 간
유의한 차이 존재)

사후 검정 (Wilcoxon signed-rank, Bonferroni 보정 α = 0.05/6 = 0.0083):

| 비교 | p-value | 유의성 (α=0.0083) |
|------|---------|---------------------|
| A vs. B | 0.00021 | 유의 |
| A vs. C | 0.0410 | **유의하지 않음** |
| A vs. D | < 0.0001 | 유의 |
| B vs. D | 0.0064 | 유의 |
| C vs. D | 0.00089 | 유의 |

조건 C − 조건 A (MRR@10 차이, 전체): **Δ = +0.023** — 해석 기준(+0.03) **미달**,
사후 검정에서도 통계적 유의성이 확인되지 않았다.

### 6.4 `has_content` 그룹별 VLM 기여도 세부 분석

| 그룹 | 조건 A MRR@10 | 조건 C MRR@10 | Δ(C−A) |
|------|---------------|---------------|--------|
| `has_content=TRUE` (n=560) | 0.542 | 0.552 | +0.010 |
| `has_content=FALSE` (n=240) | 0.463 | 0.531 | **+0.068** |

전체 평균 Δ(+0.023)는 해석 기준에 못 미쳤지만, 표본의 70%를 차지하는
`has_content=TRUE` 그룹에서 VLM 기여가 거의 없다시피 희석된 결과이며(Δ=+0.010),
`has_content=FALSE` 그룹만 놓고 보면 Δ=+0.068로 해석 기준을 두 배 이상
초과한다. 즉 VLM 메타의 검색 기여도는 트랜스크립트 유무에 따라 근본적으로
다른 양상을 보인다.

### 6.5 정성적 사례 분석

**사례 1 (VLM 기여 큼, `has_content=FALSE`)** — 쿼리 "노트북 거치대 각도조절".
대상 영상은 자막이 없는 숏폼 제품 리뷰로, 제목이 "이거 하나면 끝"이라 API
메타만으로는 쿼리와의 연관성이 낮아 조건 A에서 17위에 머물렀다. VLM
visual_summary는 "은색 알루미늄 재질의 각도조절형 노트북 거치대가 책상 위에
놓여 있다", dominant_objects는 `["노트북 거치대", "알루미늄 프레임", "데스크"]`
로 추출되었고, 이 신규 정보 덕분에 조건 C에서 4위로 상승했다(Δrank=+13).

**사례 2 (반례, 신규 정보는 많지만 검색 기여 없음)** — 쿼리 "AI 반도체 시장
전망". 관련 영상에 대해 VLM은 visual_emotion=dramatic, layout_type=face-centered,
dominant_objects=`["발표자", "마이크", "무대"]`를 출력했다. 이는 트랜스크립트
LLM 메타에 없는 명백한 신규 정보였으나, 쿼리와 무관한 일반적 인물 사진 묘사에
불과해 검색 순위에는 변화가 없었다(Δrank=0). 즉 "신규 정보"라는 사실 자체가
"쿼리 관련성"을 보장하지 않는다 — Jaccard 기반 지표는 정보의 존재 유무만
측정할 뿐 그 정보가 특정 검색 의도에 유용한지는 측정하지 못한다.

## 7. 논의

**VLM 메타데이터 품질** — 인간 평가 평균 3.77점으로 해석 기준(≥3.5)을
충족했고, 평가자 간 일치도(α=0.71)도 양호해 평가 자체의 신뢰도는 확보된
것으로 판단된다. GPT-4V(4.40점) 대비 0.63점 낮은 수준은 무료 소형(7B) 모델의
합리적인 트레이드오프로 해석된다.

**신규 정보 비율은 목표를 충족했지만 검색 기여로는 불완전하게 전환됨** — 전체
신규 정보 비율(45.4%)은 해석 기준(30%)을 크게 상회했다. 그러나 조건 C의 전체
평균 MRR@10 향상(+0.023)은 해석 기준(+0.03)에 미달했고 사후 검정에서도 유의성이
확인되지 않았다. 이는 "VLM이 새로운 정보를 많이 찾아낸다"는 사실과 "그 정보가
검색 성능을 유의미하게 끌어올린다"는 결과가 반드시 함께 가지 않음을 보여준다.
§6.5의 사례 2가 이 간극의 메커니즘을 잘 보여준다 — dominant_objects나
visual_emotion처럼 트랜스크립트에 없는 신규 키워드라도, 그것이 특정 쿼리의
검색 의도와 무관하면 순위에 반영되지 않는다. 신규 정보 비율은 "정보의 존재"를
셀 뿐 "정보의 검색 적합성"을 측정하지 않는다는 한계가 여기서 드러난다.

**`has_content` 그룹 분해가 드러낸 핵심 패턴** — 전체 평균 Δ가 기준에 못 미친
근본 원인은 표본의 70%를 차지하는 `has_content=TRUE` 그룹에서 VLM의 한계
기여도가 거의 0에 가까웠기(+0.010) 때문이다. 반면 `has_content=FALSE` 그룹
(30%)에서는 Δ=+0.068로 기준을 두 배 이상 초과했다 — 이는 애초에 제안했던
기여점("트랜스크립트 없는 영상에서 VLM 대체 활용 가능성")을 강하게 뒷받침한다.
다시 말해, VLM 메타의 가치는 "모든 영상에 걸쳐 고르게" 나타나는 것이 아니라
**트랜스크립트가 존재하지 않을 때 집중적으로** 나타난다. 전체 평균 지표만
보고 "VLM 메타는 기준 미달"이라고 결론짓는 것은 표본 구성(has_content 비율)에
따라 결과가 완전히 달라질 수 있다는 점을 간과한 것이다 — 만약 `has_content=FALSE`
비율이 높은 채널(예: 자막 없는 숏폼 위주 채널)에 적용한다면 전체 평균 Δ도
기준을 상회할 것으로 예상된다.

**조건 D의 함의** — 조건 D(전체 결합)는 조건 B 대비 유의하게 높았다(사후 검정
*p*=0.0064). 이는 이미 트랜스크립트 메타가 존재하는 상황에서도 VLM 메타가
소폭이나마 추가 가치를 제공함을 시사한다 — 한계 기여도는 작지만 0은 아니다.

**Friedman 검정 유의성의 원천** — 전체 Friedman 검정이 유의했던 것(p=0.00031)은
주로 트랜스크립트 채널(B, D)의 강한 기여 때문이며, VLM 단독(C)의 기여는 이보다
약하고 통계적으로도 불안정하다. 이는 P03(트랜스크립트 메타)이 여전히 핵심
채널이고, VLM 메타는 보조적이되 특정 조건(트랜스크립트 부재)에서는 대체
불가능한 역할을 한다는 것으로 요약할 수 있다.

## 8. 한계

- 인간 품질 평가 대상이 100편, 평가자 3인으로 제한적 — 통계적 검정력의 한계
- GPT-4V를 upper bound로 사용했으나 이 역시 완벽한 gold standard는 아니다
- Jaccard 기반 신규 정보 비율은 표층 키워드 일치만 측정하며, §6.5 사례 2처럼
  "신규 정보"가 곧 "검색에 유용한 정보"를 의미하지 않는다는 근본적 한계가
  실증되었다
- 전체 평균 지표(신규 정보 비율 45.4%, Δ MRR@10 +0.023)는 표본의
  `has_content` 비율(TRUE:FALSE = 7:3)에 강하게 의존한다 — 이 비율이 다른
  코퍼스에서는 결과가 달라질 수 있어 일반화에 주의가 필요하다
- Groq `llava-v1.5-7b`는 소형 VLM으로, 프롬프트에 명시한 4종 항목 외의 세부
  시각 정보를 놓칠 수 있다
- 4조건 Ablation은 50개 쿼리에 한정되어 있어 조건 A vs. C처럼 효과 크기가
  작은 비교에서는 검정력 부족으로 실제로는 존재하는 차이를 놓쳤을 가능성을
  배제할 수 없다

## 9. 결론

본 연구는 Groq Vision API 기반 VLM으로 한국어 YouTube 썸네일에서 4종 구조화
메타데이터를 추출하는 파이프라인을 구축하고, 트랜스크립트 기반 LLM 메타(P03)
와의 보완성을 실증했다. VLM 메타데이터 품질은 실용 수준(3.77/5)이었고, 신규
정보 비율(45.4%)도 목표(30%)를 크게 상회했다. 그러나 이 신규 정보가 검색
성능 향상으로 이어지는 정도는 트랜스크립트 유무에 따라 뚜렷하게 갈렸다 —
전체 평균 MRR@10 향상(+0.023)은 해석 기준에 못 미쳤지만, 트랜스크립트가 없는
영상(`has_content=FALSE`)만 놓고 보면 향상폭(+0.068)이 기준을 두 배 이상
상회했다. 이는 VLM 썸네일 메타데이터가 모든 영상에 균일하게 기여하는 범용
채널이 아니라, **트랜스크립트 부재라는 특정 조건에서 선택적으로 강한 대체
정보원**으로 기능한다는 것을 시사한다.

향후 연구로는 (1) 신규 정보 비율에 "쿼리 관련성" 가중치를 추가한 개선된
보완성 지표 설계, (2) `has_content=FALSE` 영상 비율이 높은 채널·카테고리를
대상으로 한 후속 실증, (3) VLM 메타 계산을 `has_content=FALSE` 영상에만
선택적으로 적용해 API 비용을 절감하는 조건부 파이프라인 설계를 고려할 수 있다.
