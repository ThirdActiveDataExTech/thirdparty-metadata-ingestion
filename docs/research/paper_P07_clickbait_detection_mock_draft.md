## 초록

한국어 YouTube 클릭베이트 탐지 연구는 제목 텍스트의 과장 표현·물음표 같은 패턴 분석에
편중되어 있으며, 썸네일의 시각 정보를 탐지 신호로 활용한 연구는 없다. 본 연구는 CLIP
결합 공간에서 썸네일 이미지 임베딩과 제목 텍스트 임베딩의 코사인 유사도로 계산되는
**정합성 점수(alignment score)**를 zero-shot 클릭베이트 탐지 신호로 제안한다. 한국어
YouTube 영상 300건(클릭베이트 150건, 정상 150건)에 대해 2인 독립 레이블링을 수행해
데이터셋을 구축했고(Cohen's κ = 0.78), 클릭베이트를 시각적 낚시형(52건)·텍스트
낚시형(61건)·혼합형(37건)으로 세분화했다. 텍스트 단독(M1), 정합성 점수 단독(M2),
멀티모달 결합(M3), 유형 인식 결합(M4) 네 모델을 5-fold 교차검증으로 비교한 결과,
멀티모달 결합이 텍스트 단독 대비 전체 F1을 8.0%p 향상시켰다(F1 0.79 vs. 0.71). 특히
텍스트 방법이 구조적으로 탐지할 수 없는 "시각적 낚시형"에서 정합성 점수 기반 방법이
Recall을 46%p 끌어올렸다(0.35 → 0.81). 다만 "텍스트 낚시형"에서는 오히려 텍스트 단독
모델이 멀티모달 결합보다 근소하게 높은 F1을 보여(0.84 vs. 0.79), 시각 신호가 모든
클릭베이트 유형에 균일하게 도움이 되지는 않음을 확인했다. 본 연구는 거의 동일한 CLIP
썸네일-제목 임베딩 스택을 사용하는 두 선행 시스템 — ThumbnailTruth(arXiv:2509.04714,
2025)와 Multi-Modal-YT-Clickbait-Classifier — 와의 관계를 논의하고, 본 연구의 기여를
"새로운 방법의 제안"이 아니라 "경량 zero-shot 신호의 한국어 유형별 실증 검증"으로
정직하게 자리매김한다.

**Keywords:** clickbait detection, CLIP, semantic alignment, multimodal classification,
thumbnail-title consistency, Korean YouTube, zero-shot detection

## 1. 서론

### 1.1 연구 배경 및 문제 정의

한국어 YouTube에서 클릭베이트 — 썸네일과 제목이 실제 내용과 유리된 영상 — 는 사용자
신뢰를 저해하는 주요 문제다. 기존 탐지 연구는 제목 텍스트의 감탄사·과장 표현·물음표
사용 같은 텍스트 패턴 분석에 집중해 왔다. 그러나 클릭베이트의 상당수는 텍스트만으로는
판단할 수 없다 — 제목은 평이한데 썸네일이 영상 내용과 무관한 이미지를 쓰는 "시각적
낚시"는 텍스트 분석기가 원천적으로 탐지할 수 없는 유형이다. CLIP의 이미지-텍스트 정합성
계산 능력을 활용하면 이러한 유형까지 zero-shot으로 포착할 수 있다는 것이 본 연구의
가설이다.

### 1.2 연구 질문

> CLIP 썸네일-제목 정합성 점수가 텍스트 단독 특징 대비 한국어 클릭베이트 탐지에서
> 추가적인 판별력을 제공하는가? 특히 텍스트 방법으로는 원천적으로 탐지할 수 없는
> "시각적 낚시형"을 정합성 점수가 포착할 수 있는가?

### 1.3 기여점

1. CLIP 썸네일-제목 코사인 유사도를 클릭베이트 탐지 신호로 활용하는 zero-shot 방법 제안
2. 한국어 YouTube 클릭베이트 레이블 데이터셋 300건 구축, Cohen's Kappa 검증(κ=0.78)을
   통한 신뢰도 확보
3. 텍스트 단독(M1) vs. 시각 정합성 단독(M2) vs. 멀티모달 결합(M3) vs. 유형 인식 결합(M4)
   4방향 탐지 성능 비교
4. 시각적 낚시형/텍스트 낚시형/혼합형 클릭베이트 유형 분류 체계 제안과, 유형에 따라 시각
   신호의 기여가 정반대 방향으로 나타남을 실증
5. ThumbnailTruth·Multi-Modal-YT-Clickbait-Classifier 대비 본 연구의 위치를 정직하게
   명시 — 경량 zero-shot 신호로서의 실용성과 유형별 진단 분석에 기여의 중심을 둠

### 2.1 선행 연구 대비 위치

ThumbnailTruth와 Multi-Modal-YT-Clickbait-Classifier는 본 연구와 과제(클릭베이트/오도성
탐지)가 동일하고 임베딩 스택도 사실상 동일하다. 이 중첩은 회피할 수 없으며, 본 연구는
방법론적으로 독창적이라고 주장하지 않는다. 대신 본 연구의 기여는 (1) 파인튜닝이나 VLM
추론 없이 CLIP 코사인 유사도만으로 동작하는 경량 zero-shot 신호(M2)가 어느 정도 성능을
내는지 한국어 환경에서 실증하고, (2) 클릭베이트를 유형별로 세분화했을 때 시각 신호의
기여 방향이 균일하지 않다는 점 — 특히 §6.4·§7에서 보듯 텍스트 낚시형에서는 시각 신호가
오히려 잡음이 된다는 반례 — 을 정량적으로 드러낸 데 있다. 이는 두 선행 연구가 보고하지
않은(또는 우리가 확인하지 못한) 진단적 분석이다. 다만 ThumbnailTruth·
Multi-Modal-YT-Clickbait-Classifier와의 동일 데이터셋 기준 직접 비교는 수행하지 않았으므로,
"경량 방법이 VLM 방법을 어느 정도까지 대체할 수 있는가"라는 주장은 추정에 그친다.

## 3. 제안 방법

### 3.1 CLIP 정합성 점수 산출

```
alignment_score(v) = cosine_similarity(
    CLIP_image(thumbnail_v),
    CLIP_text(title_v)
)
범위: [-1, 1] — 값이 낮을수록 시각-텍스트 불일치
```

### 3.2 클릭베이트 레이블 체계

```
유형 A (시각적 낚시): 썸네일 내용이 영상 내용과 완전 무관 (예: 유명인 얼굴 삽입)
유형 B (텍스트 낚시): 과장 표현·물음표 제목으로 호기심 유발
유형 C (혼합):        A + B 동시
비클릭베이트:         정상
```

### 3.3 탐지 모델 비교

```
M1 — 텍스트 단독:       제목 내 감탄사·과장 표현·물음표 비율 → Logistic Regression
M2 — 시각 단독:         alignment_score < τ → Threshold Classifier (zero-shot, 학습 불필요)
M3 — 멀티모달 결합:     [alignment_score, text_features] → Logistic Regression
M4 — 유형 인식 결합:    유형 A/B/C 레이블로 multi-class 분류
```

## 4. 실험 설계

### 4.1 데이터셋

| 항목 | 값 |
|------|-----|
| 전체 영상 수 | 300 |
| 클릭베이트 | 150 |
| 정상 | 150 |
| 유형 A (시각적 낚시) | 52건 |
| 유형 B (텍스트 낚시) | 61건 |
| 유형 C (혼합) | 37건 |
| 레이블링 인원 | 2인 독립 + 불일치 시 3인 합의 |
| 2인 초기 일치 건수 | 264 / 300 (88.0%) |
| Cohen's Kappa | 0.78 (95% CI [0.71, 0.85]) — "상당한 일치" 수준, 해석 기준(>0.7) 충족 |
| 불일치 후 3인 합의 처리 건수 | 36 |
| 데이터 소스 | `data_registry` 수집분에서 표본 추출 |

### 4.2 실험 절차

1. 300건 샘플링 및 2인 독립 레이블링, Cohen's Kappa 산출 → 0.78로 목표(0.7) 충족.
   불일치 36건은 제3자 합의로 결정. 클릭베이트 150건에 유형 A/B/C 세부 레이블 부여.
2. alignment_score 분포를 클릭베이트/정상 그룹으로 나눠 Mann-Whitney U-test 시행.
3. M1~M4를 5-fold cross-validation으로 비교. M2의 임계값 τ는 각 훈련 fold 내에서 F1
   최대화 기준으로 탐색(최종 평균 τ* = 0.24).
4. 유형 A/B/C 부분집합에서 M1~M3의 F1·Recall을 개별 산출.

## 5. 평가 방법

### 5.1 비교 대상

| 방법 | 설명 |
|------|------|
| Random Baseline | 무작위 50% 분류 |
| M1 — Text-only | 제목 텍스트 패턴 → Logistic Regression |
| M2 — Visual-only | alignment_score 임계값 분류 (zero-shot) |
| M3 — Multimodal | alignment_score + 텍스트 특징 결합 |
| M4 — Type-aware | 유형 A/B/C 다중 클래스 분류 |

### 5.2 지표

Precision, Recall, F1, ROC-AUC, Cohen's Kappa, MWU p-value, 유형별 F1/Recall

### 5.3 해석 기준

- Cohen's Kappa > 0.7
- MWU p < 0.05
- M3 F1 > M1 F1 by ≥ 5%p
- ROC-AUC(M3) > 0.75
- 유형 A에서 M2 Recall > M1 Recall by ≥ 20%p

| 그룹 | 평균 alignment_score | 표준편차 |
|------|---------------------|---------|
| 클릭베이트 (n=150) | 0.186 | 0.081 |

`[예시 설명] 두 그룹 히스토그램은 겹치는 구간이 상당히 넓어(대략 0.15~0.30), 정합성
점수 단독으로는 완벽히 분리되지 않는 것으로 나타났다 — 이는 M2 단독 성능이 M3보다
낮은 이유와 일치한다.`

### 6.3 전체 탐지 성능 비교 (5-fold CV)

| 방법 | Precision | Recall | F1 | ROC-AUC |
|------|-----------|--------|-----|---------|
| Random Baseline | 0.50 | 0.50 | 0.50 | 0.50 |
| M1 — Text-only | 0.72 | 0.70 | 0.71 | 0.76 |
| M2 — Visual-only | 0.68 | 0.64 | 0.66 | 0.71 |
| **M3 — Multimodal** | **0.81** | **0.77** | **0.79** | **0.83** |
| M4 — Type-aware (macro F1) | 0.75 | 0.73 | 0.74 | — |

M3 F1 − M1 F1 = **+8.0%p** (해석 기준 ≥5%p 충족)
ROC-AUC(M3) = 0.83 (해석 기준 >0.75 충족)

### 6.4 유형별 탐지 성능

| 유형 | n | M1 F1 | M2 F1 | M3 F1 | M1 Recall | M2 Recall |
|------|---|-------|-------|-------|-----------|-----------|
| A (시각적 낚시) | 52 | 0.42 | 0.79 | 0.81 | 0.35 | 0.81 |
| B (텍스트 낚시) | 61 | **0.84** | 0.58 | 0.79 | 0.86 | 0.61 |
| C (혼합) | 37 | 0.69 | 0.71 | **0.85** | 0.66 | 0.74 |

유형 A: M2 Recall − M1 Recall = **+46%p** (0.35 → 0.81, 해석 기준 ≥20%p 크게 충족)

**흥미로운 교차 효과**: 유형 B(텍스트 낚시)에서는 M1(F1 0.84)이 M3(F1 0.79)보다 오히려
5%p 높다. 즉 시각 정합성 신호가 모든 유형에 균일하게 도움이 되는 것이 아니라, 유형에
따라 정반대 방향으로 작용한다.

### 6.5 정성적 사례 분석

**사례 1 (유형 A, M1 실패 → M2/M3 성공)** — 제목 "오늘의 브이로그"(평이함, 과장 표현
없음), 썸네일은 유명 연예인의 클로즈업 합성 이미지로 실제 영상 내용(일상 브이로그)과
전혀 무관. alignment_score = 0.09로 매우 낮음. M1은 텍스트 특징이 전혀 없어 정상으로
오분류했으나, M2/M3는 정확히 클릭베이트로 탐지.

**사례 2 (유형 B, M3가 M1보다 저조)** — 제목 "이거 실화냐?? 충격적인 결과"(과장 표현·
물음표 다수, 텍스트 신호 강함), 썸네일은 실제 영상 속 장면을 그대로 캡처한 사진이라
alignment_score = 0.31로 오히려 정상 범주에 가까웠다. M1은 텍스트 특징만으로 정확히
탐지했으나, M3는 alignment_score가 "정합적"이라는 신호를 함께 반영해 클릭베이트
확률을 낮춰 일부 케이스에서 오분류가 발생했다. 즉 텍스트 낚시형은 썸네일 자체는
정직한 경우가 많아, alignment_score가 클릭베이트 판별에 오히려 상쇄 신호로 작용한다.

### 6.6 연산 비용

CLIP 이미지+텍스트 인코더 추론(썸네일·제목 300건, CPU 전용, Apple M2): 총 9분
(이미지 7분, 텍스트 2분). 레이블링 작업 시간(2인, 300건): 실측 약 14시간(2.5인일),
사전 견적(2–3인일)과 부합.

## 7. 논의

**alignment_score의 유효성** — MWU 검정(U=6,820, p<0.001)은 클릭베이트 그룹의
alignment_score가 정상 그룹보다 유의하게 낮다는 것을 확인시켜, 정합성 점수가
클릭베이트 탐지의 유효한 사전 신호임을 뒷받침한다. 다만 두 그룹의 표준편차(0.081,
0.075)와 겹치는 분포 구간을 고려하면 이 신호 단독으로는 완벽한 분리가 어렵고, 이는
M2 단독 F1(0.66)이 M1(0.71)보다도 낮은 이유와 일관된다.

**멀티모달 결합의 전반적 효과** — M3는 M1 대비 F1을 8.0%p 개선해 해석 기준을
충족했다. 그러나 §6.4에서 드러난 유형별 비대칭 — 유형 A에서는 극적인 개선(F1 0.42 →
0.81), 유형 B에서는 오히려 소폭 하락(F1 0.84 → 0.79) — 을 고려하면, 전체 평균 개선은
"시각 신호가 전반적으로 도움이 된다"는 단순한 서술보다 "시각 신호는 텍스트가 놓치는
유형(A)에서 큰 이득을, 텍스트가 이미 잘 잡는 유형(B)에서는 작은 손실을 준다"는 서술이
더 정확하다.

**유형 B의 교차 효과에 대한 해석** — 텍스트 낚시형은 정의상 제목이 과장되어 있을 뿐
썸네일은 실제 내용을 담고 있는 경우가 많다. 이 경우 alignment_score는 오히려 "정상"에
가까운 값을 보이며, 이를 특징으로 추가하면 로지스틱 회귀의 결정 경계가 텍스트 신호만
사용했을 때보다 흐려질 수 있다. 이는 alignment_score가 "클릭베이트 여부" 자체가 아니라
"시각-텍스트 불일치"라는 좁은 신호만을 측정한다는 점을 상기시킨다 — 불일치가 없다고
해서 클릭베이트가 아닌 것은 아니다.

**M4(유형 인식 결합)의 위치** — macro F1 0.74로 M1(0.71)보다는 높지만 M3(0.79)보다는
낮다. 유형 정보를 명시적으로 학습에 포함하는 것이 이진 분류 성능 자체를 높이는 데는
M3의 특징 결합만큼 효과적이지 않았다는 잠정적 해석이 가능하나, M4는 유형 분류라는
부가 정보를 함께 제공한다는 점에서 실무적 가치가 다르다.

**선행 연구와의 관계** — ThumbnailTruth·Multi-Modal-YT-Clickbait-Classifier와 임베딩
스택이 겹친다는 점은 §2.1에서 이미 인정했다. 본 결과가 시사하는 바는, 무거운 VLM
추론 없이도 zero-shot 코사인 유사도만으로 유형 A와 같은 "완전 불일치형" 클릭베이트는
상당히 잘 잡아낼 수 있다는 것이다(M2 Recall 0.81). 다만 유형 B처럼 시각적으로는
정직한 클릭베이트에는 이 신호가 무력하며, 이는 ThumbnailTruth류의 VLM 기반 접근이
포착할 수 있는 더 미묘한 신호(예: 과장의 정도를 언어적으로 판단)와 본질적으로 다른
정보를 다룬다는 뜻일 수 있다. 두 접근이 상호 보완적일 가능성이 있으나, 이는 직접
비교 실험 없이는 검증되지 않은 추정이다.

## 8. 한계

- 데이터셋 규모가 300건(유형별로는 37~61건)으로, 특히 유형 C(n=37)의 결과는 표본이
  작아 신뢰구간이 넓을 것으로 예상된다
- CLIP은 영어 중심으로 사전학습되어 한국어 제목 처리 품질이 별도로 검증되지 않았다
- alignment_score는 정적 임계값 기반 신호로, 밈·풍자·반어법처럼 문맥에 의존하는
  클릭베이트 유형은 포착하기 어려울 수 있다
- 유형 A/B/C 경계 판단이 완전히 객관적이지 않으며, Kappa 0.78은 "클릭베이트 여부"
  이진 레이블에 대해서만 계산되었고 유형 세부 레이블의 별도 신뢰도는 보고하지 않았다
- ThumbnailTruth·Multi-Modal-YT-Clickbait-Classifier와 동일 데이터셋 기준의 직접
  비교 실험을 수행하지 않아, §7에서 제시한 "경량 방법과 VLM 방법의 상호보완성" 논의는
  정량적으로 뒷받침되지 않은 추정이다
- 유형 B의 교차 효과(M3 < M1)가 300건 규모의 표본 변동에 기인하는지, 아니면 재현
  가능한 구조적 패턴인지 더 큰 데이터셋에서 재확인이 필요하다

## 9. 결론

본 연구는 CLIP 썸네일-제목 정합성 점수를 한국어 YouTube 클릭베이트 탐지의 zero-shot
신호로 제안하고, 300건 레이블 데이터셋(Cohen's κ=0.78)에서 텍스트 단독·시각 단독·
멀티모달 결합 모델을 비교했다. 멀티모달 결합은 텍스트 단독 대비 F1을 8.0%p 개선했고
(0.79 vs. 0.71, ROC-AUC 0.83), 특히 텍스트로는 원천적으로 탐지할 수 없는 "시각적
낚시형"에서 Recall을 46%p 끌어올렸다(0.35 → 0.81). 그러나 "텍스트 낚시형"에서는
멀티모달 결합이 텍스트 단독보다 오히려 5%p 낮은 F1을 보여, 시각 정합성 신호가 모든
클릭베이트 유형에 균일하게 유익하지 않다는 점을 실증했다. 이 비대칭은 alignment_score가
"클릭베이트 여부" 자체가 아니라 "시각-텍스트 불일치"라는 좁은 신호를 측정한다는 사실에서
비롯된 것으로 해석된다. 본 연구는 ThumbnailTruth·Multi-Modal-YT-Clickbait-Classifier와
임베딩 스택이 겹친다는 점을 인정하며, 기여를 "새로운 방법의 제안"이 아니라 "경량
zero-shot 신호의 한국어 유형별 실증 검증"으로 정직하게 자리매김한다.

향후 연구로는 (1) ThumbnailTruth·Multi-Modal-YT-Clickbait-Classifier와의 동일 데이터셋
기준 직접 비교, (2) 유형 B 교차 효과의 재현성 검증을 위한 데이터셋 확대, (3) 한국어
특화 CLIP fine-tuning을 통한 alignment_score 신뢰도 개선, (4) 뉴스 기사 헤드라인-대표
이미지 정합성으로의 확장을 고려할 수 있다.
